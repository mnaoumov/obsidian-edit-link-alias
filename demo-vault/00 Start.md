# Start here

Welcome to the [Edit Link Alias](https://github.com/mnaoumov/obsidian-edit-link-alias/) demo vault. This plugin adds an **Edit link alias** command that changes the **display text** of the link under your cursor - internal, markdown, or external - without hand-editing the link syntax, plus an **Edit link (URL and alias)** command that edits the target and the display text together. Both are available from the Command Palette, the editor right-click menu, and the link long-press / Reading-view context menu.

Links in a note's **properties** are covered too, written back through the frontmatter so the YAML stays valid - see [05 Frontmatter links](<./05 Frontmatter links.md>).

**How to try it:** `Alt` + click a link (`Option` + click on macOS) to edit it right where it is - see [04 Alt click a link to edit it](<./04 Alt click a link to edit it.md>). The same editors are also on the Command Palette, the editor right-click menu, and the link long-press / Reading-view context menu: **Edit link alias** for an alias-only prompt, **Edit link (URL and alias)** for the two-field pop-up.
